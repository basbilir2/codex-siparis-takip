Kaynak dosyalar `source/` altında dönemleriyle korunur. Orijinal çalışma klasörleri değiştirilmedi. Gizli değerler yükleme kopyasında maskelenebilir; maskeleme kayıtları varsa `reconstruction/PRIVACY.json` içindedir. Müşteri verisi ve kişisel içerik arşivlenmez.

Bu depo mevcut bulunan çalışmayı korur; tamamlanmamış projeyi tamamlanmış veya yeniden kurulum testi yapılmış saymaz.

Kişisel kişi/müşteri adları, iletişim bilgileri ve gerçek finansal kayıtlar kapsam dışıdır. Kişiye özel sabitler anonim yer tutucularla gösterilir; gerekli ayarlar yalnız yerel ortamda sağlanır.
